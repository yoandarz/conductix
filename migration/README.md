# Migración privada
Los datos originales de Conductix NO están incluidos en este repositorio. El archivo `Conductix_MIGRACION_PRIVADA_2026-08-18.json` se entrega aparte. Desde Conductix > Configuración > Migrar Conductix clásico, selecciónalo una sola vez y luego sincroniza. No subas ese JSON a GitHub: contiene datos personales.
